Privacy Policy

Home Dashboard · Last updated October 26, 2026

Home Dashboard is a personal application that runs on a single PC in its owner's home. It is used only by its owner, and it is not offered to anyone else. This policy explains what it does with Google user data.

What data it accesses

When the owner signs in with Google, Home Dashboard uses the Google Smart Device Management API and Google Cloud Pub/Sub to access the owner's own Google Nest devices:

  • Thermostat status and settings: temperature, humidity, mode, target temperatures and eco mode.
  • Camera and doorbell information: names, live video when the owner chooses to watch, and event notifications (motion, person, sound, doorbell) with their preview clips.

It does not access email, contacts, files or any other Google account data.

How the data is used

The data is used only to show the owner's devices on their private home dashboard, and to send the thermostat changes the owner makes there. It is not used for advertising, profiling, analytics or any other purpose.

Where the data is stored

  • The Google sign-in token and the list of recent camera events are stored only on the owner's home PC.
  • Live video is streamed directly to the owner's browser and is not recorded.
  • No data is sent to any server other than Google's own.

Sharing

Google user data is never sold, shared with, or transferred to anyone else.

Google API Services User Data Policy

Home Dashboard's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Removing access

Access can be revoked at any time from the dashboard's settings, or from myaccount.google.com/permissions. Deleting the app's files from the home PC removes all stored data.
